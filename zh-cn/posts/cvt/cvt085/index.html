Edge 模式的音色 Sound colours in Edge
#

若想改变模式的音色，你必须改变声道的形状。我们可以从各个方向角度调整声道的形状，所以改变音色的方法有无数种。

请参阅 “音色”

在 Edge 模式下，音色通常偏亮且尖锐，但也可以向其他方向变化。在 Edge 模式下塑造亮音色并不难，但如果你想塑造暗音色，你就必须对三大总体原则进行完美掌控。不仅如此，你还必须对自己的声音了如指掌，以便在超出健康极限时有所察觉。重要的是，“金属” 音越亮，就越能防止声音使用不当。如果你可以毫无问题地控制模式，你才应该尝试在 Edge 模式下使音色更暗。

只有当你能够毫无问题地控制 Edge 时，你才能尝试改变音色——但即使这样也只能稍微改变一下。你可以通过改变声道的形状和位置来做到这一点，但请记住，在使音色变暗时可能会出现问题。音色越暗，丢失 “金属” 音的风险越大。请记住保持清晰的强 “金属” 音和大量的 twang，以免脱离 Edge 模式。

Edge 模式的亮音色 Lighter sound colour in Edge
#

如果你想使Edge更亮，你必须减小声道的尺寸。可通过以下一种或多种方法实现：

  • 挤压会厌漏斗制造大量的 twang
  • 进一步抬高喉位
  • 放松软腭
  • 打开口腔，像在微笑一样
  • 进一步展宽舌头
  • 进一步打开鼻腔通道

Edge 模式的不那么亮的音色 Less light sound colour in Edge
#

如果你想在 Edge 模式下创造更柔和或更暗的音色，你可以稍微增大声道的尺寸。可通过以下一种或多种方法实现：

  • 少些挤压会厌漏斗制造 twang。对此要非常小心。请记住，大量的 twang 是 Edge 模式的必要条件。
  • 如果你很有经验，你可以尝试稍微压低喉位。再次提醒，注意不要失去清晰、强 “金属” 音和大量的 twang。请记住，Edge 越亮，模式越安全。
  • 如果你经验丰富，可以尝试稍微提软腭。注意不要过度提上颚，以免失去清晰饱满的 “金属” 音和大量的 twang，因为这样可能会造成疼痛和损伤。
  • 放松嘴角，口型打开更大，但不要丢失 “咬住” 的动作。再次提醒，注意不要失去清晰、强 “金属” 音和大量的 twang。
  • 舌头下凹成直沟。这样发音类似歌剧唱法。再次提醒，注意不要失去清晰、强 “金属” 音和大量的 twang。
  • 关闭鼻腔通道。

在 Edge 模式下练习不那么亮的音色

熟练掌握 Edge 并有能力改变音色后，也要记得定期回到模式中心区练习。这可能听起来太尖锐，但重要的是要找到健康的模式中心区，这样你才不会在尝试时迷失方向。

案例故事 A case story
#

一位摇滚歌手在唱高音时遇到了问题。她上过很多歌唱课，但觉得自己没有进步，对练习感到厌倦。

我让她像在舞台上那样唱歌，然后给我看她做的练习。她做练习时使用的是 Neutral 模式，但她在舞台上唱歌时主要使用的是 Edge 模式。因此，她的练习对提高歌唱没有任何效果，这是完全合理的。如果你想提高在 Edge 模式下的歌唱能力，你必须在 Edge 模式下练习。

当我们练习 Edge 模式中心区时，我发现她的会厌漏斗挤压不够，这就是她难以达到高音的原因。当她在练习中掌握了正确的 Edge 模式时，我们便把这项技术运用到歌曲中。然后，我们不得不解决引起她问题的元音。这些元音被改为 “I”（如在 “sit” 中）、“EH”（如在 “stay” 中）、“A”（如在 “and” 中）和 “OE”（如在 “herb” 中）。一旦她掌控了 Edge 的正确位置，并在 Edge 模式下使用了正确的元音，高音对她来说就不再是问题了。

古典唱法里的 Edge 模式 Edge in classical singing
#

在古典乐中，在中等至响亮（mf-ff）的音量下，Edge 常用来表现清晰的 “金属” 音（“金属” 音通常很难捕捉到，因为它被较暗的音色所掩盖）。古典男歌手可以在所有音区使用 Edge 模式，Edge 在高音区听感清晰，比如男高音唱 C5。古典女歌手在中低音区以中等至响亮音量的演唱时，大多采用 Edge 模式。

技术上很难在 Edge 模式下使用古典唱法所需的暗音色。你只有在习惯了古典唱法、完全掌握了 Edge，并了解正确使用声音的三大总体原则后，才能尝试这种唱法。不仅如此，你还必须对自己的声音了如指掌，以便在超出健康极限时有所察觉。

从 Edge 模式的中心区开始练习 。熟悉强大，明亮，清晰的金属特征。现在，请谨慎地试着提软腭，放松嘴角、打开口腔、下凹舌头成直沟，关闭鼻腔通道——保证所有这些动作都不会影响清晰饱满的 “金属” 音和大量的 twang。在你舒服的音高下单音，音高逐渐升高时保持这种声音。

熟悉这种感觉后，尝试一下 - 仍然只唱单音 - 看看你能在不明亮清晰的 “金属” 音情况下将喉位压低多少。声道越大，音色就越暗、越古典。

古典男歌手，在需要非常响亮和穿透力的音量时（例如卢西亚诺·帕瓦罗蒂和普拉西多·多明戈），会在 A4-Bb4 左右及以上使用 Edge 模式。

案例故事 A case story
#

一家大型歌剧公司的首席男高音遇到了严重的问题，因为他的声音在高音 C 处开始破音。他一直觉得高音 C 不稳定，因为他不知道自己能否保持高音 C，也不知道声音是否会破音。但现在，声音总是破音。他非常绝望，因为当晚他就要唱歌了，而他的练习却越练越糟。

事实证明，他和许多歌剧演员一样，被教导要将喉咙尽量放低。他越这样，高音就越受影响。我们最初的练习是喉位随着音的升高逐渐抬高。他的声音变得更稳定，几乎所有的元音都能发准，即使音量很小。为了在高音上获得更有力的音量，我们在 Edge 模式下加入了大量的 twang，直到他掌握了这种饱满的 “金属” 音。

过了一段时间，在只使用元音 “I” (如在 “sit” 中)、“EH” (如在 “stay” 中)、“A” (如在 “and” 中) 和 “OE” (如在 “herb” 中) 的情况下，他就能在 Edge 模式中心区用高音区唱出所有音，高音不再颤抖，他甚至可以发出非常有力的音量。之后，我们尝试通过谨慎地使音色变暗、稍微压低喉位、抬软腭和关闭鼻腔通道，使 Edge 听起来更古典。

我们还尝试将音色调暗到他的声音开始颤抖的程度。这样做是为了让他意识到，在喉位压低到一定程度之前，他就会遇到麻烦，并且知道在表演时如果发生这种情况该怎么办。每当高音快要失控时，他都会回到 Edge 模式中心区，从而稳定高音。当他完全掌控时，保持高音不再困难——他可以发出比以前更响亮的声音，并且知道如何避免声音破音。他毫无问题地完成了当晚的演出。
