## 找到 Edge Finding Edge
**Edge 模式最重要的是保持住清晰的 "金属" 音和大量的 twang**。

### 找到添加大量的 twang 的会厌漏斗的位置 Finding the distinct twang of the epiglottic funnel
要找到 Edge 模式，必须找到添加大量的 twang 的会厌漏斗的位置。

> 请参阅 "会厌漏斗" - page 188

添加 twang 时，会厌漏斗收窄。声音因此变得尖锐、更有穿透力、咆哮感，类似于大笑声。这就是 "大量的 twang"。漏斗越挤，声音就越尖锐。你可以通过增加 twang 来提高音量。

通过练习以下声音，最容易找到大量的 twang:

- 模仿婴儿的哭喊声。
- 模仿鸭子嘎嘎的叫声。
- 发出像女巫一样的声音。
- 像一个有邪恶计划的人那样说话。
- 模仿飞机俯冲的声音。
- 发出驾驶玩具车的声音。
- 模仿救护车警笛的声音。
- 像猫一样 “Meow”（但不包含尾音 “OO”），或说 “niet”。

## 找到 Edge Finding Edge
**添加大量的 twang 之后，你就可以通过增加音量来添加清晰的 "金属" 音**。随着音量的增大，保持住大量的 twang。稍微收缩一下嘴角（向内拉）可能会有所帮助。抬高喉位，展宽舌头，施用大量支承，用 Edge 模式起声。保持这种音色和强度，并发出有力、明亮、具有咆哮感的 "EH" ("stay" [ɛ])。声音应该尖锐而嘲讽，就像鸭子在呱呱叫。听起来有点鼻音没关系。注意保持大量的 twang。如果没有大量的 twang，声音就会变得不尖锐，脱离 Edge 模式。还会让人感到不适或疼痛。

在初学阶段，你可以按照建议的发声位置发声，但这不是该模式的必要条件：

- 尽可能抬高喉位
- 张大嘴巴，嘴角上扬，就像在微笑
- 展宽舌头
- 放松软腭
- 打开鼻腔通道
掌握 Edge 之后，你将不再需要用这些方法调整声道形状。熟练使用 Edge 的歌手通常有自己独特的调整方式。

初学 Edge，必须注意不要压低喉位（例如提软腭导致的喉位变低）。使用 Edge 时如果压低喉位，就可能丢失大量的 twang，从而完全脱离 Edge 模式。同时也可能让人感到不适或疼痛。只有掌握 Edge 模式、对自己的声音了如指掌，获得超过模式极限就能察觉的能力之后，你才可以尝试压低喉位。

### 通过 Overdrive 找到 Edge Finding Edge via Overdrive
比起 twang，强 "金属" 音才是重中之重。过量的 twang 会成为强 "金属" 模式的阻碍。为避免添加过量的 twang，可以先找到强 “金属" Overdrive。

先用 Overdrive 唱一个音。建立 “咬住” 的动作、施加足够的支承力，并唱长音 "EH" ("stay" [ɛ])。

> 请参阅 'Overdrive' - page 071

然后向其添加大量的 twang ，并确保你保持住 Overdrive 的音量和清晰的 "金属" 音。这就是 Edge。在初学阶段，你最好利用强 "金属" Overdrive 和强 "金属" Edge 练习，因为在这两种模式下，确认音量是否下降或清晰的 "金属" 音是否减弱会更容易。向强 "金属" Overdrive 添加大量的 twang，模式就变成了强 "金属" Edge，注意在这个过程 "金属" 音的部分要保持完全相同。

### 通过想象和身体感觉学习 Edge Achieving Edge through images and sensations
特别注意：这些想象和身体感觉仅作为辅助参考。如果你没有秒懂这些参考，忘掉它。不要将它们与实际发生的事情混淆！

- 想象你的舌头和软腭之间有一颗豌豆。尽量让豌豆保持较高的位置。

许多人使用 Edge 时，会想要通过放松会厌漏斗、压低喉位或提软腭的方式为达到大音量腾出更多空间。但如果在声道留出多余的 “空间”， "金属" 音就会消失。因此，想要添加尖锐、清晰的 "金属" 音，就别在声道创造太多空间。还有，调整的声道的过程中，你必须注意避免非自主的紧缩。
- 想象你的体内积聚了大量的能量。通过两堵无法移动的铁墙间的狭窄缝隙释放能量。

- 想象把嘴角拉出来，“系在脖子上”。像微笑那样拉伸上唇，然后打开口腔。
- 想象你正在将嘴角向中间靠拢并往里拉。将舌头放在口腔上部的臼齿上，并在使用 Edge 模式时保持这个位置。

- 用 Edge 起声，然后以同样的音色和强度继续唱歌。确保在使用 Edge 演唱的过程中保持 Edge 起声的发音位置。
- 假装你很烦，说 “哎—”。保持 twang 和舌位不变。在这个位置练习更高的音。
### 如何通过定位舌头来找到 Edge How to achieve Edge by positioning the tongue
展宽舌头可能有助于你找到大量的 twang 和抬高的喉位，从而找到 Edge。舌头展宽时，会塑造出一种亮音色。响亮的音量添加 twang ，声音就会有 "金属" 音听感。感受舌头是如何停留在口腔上部的臼齿上并向软腭拱起的，就像你说 “twang ”时那样。接触口腔上部臼齿的一定是舌头的两侧，而不是舌尖。感受一下，当你把舌头压在臼齿上时，软腭和舌头之间的空间会变得越来越小。软腭和舌头之间的空间越小，声音就越亮、越尖锐。虽然在中低音区使用所有元音时，必须保持这个位置。但在高音区演唱时，舌位就没必要固定不动了。**口型再大一些、舌头随意自然摆放，高音就更容易唱出来**。

舌头保持在展宽的位置，会更容易添加 twang，从而更易于保持 Edge。

你可以通过多种方式展宽舌头，从而找到 Edge 模式：

- 舌头在口腔上部牙齿内侧前后移动，在舌头和软腭之间形成一个小空间。
- 舌头向上顶住上颚后部的臼齿。- 放松舌尖、让它向下，同时展宽舌头。
- 将舌根向上顶住上颚磨牙内侧的牙龈。

- 确保舌头展宽，中间微拱。舌头中间不要下凹，因为下凹的舌头会导致丢失大量的 twang。

- 收紧嘴角，延伸成微笑。将舌头抵在上颚的臼齿上。保持在那里并展宽舌头。

- 说 “twang”，感受舌头与臼齿接触的位置。让舌头抵住臼齿，说 "OE" ("herb" [ɜr])，感受舌尖前端形成一个小碗状，而中段和后段则放在上颚的臼齿上。用 Edge 唱歌，请保持这种 “小碗” 的感觉。

唱一个长而轻的 “GI”（“good” [g]，"I" ("sit" [ɪ]) 音，感受舌尖在辅音 “G” 上所处的高位置。在元音 “I” 上尽量保持这个位置。
一旦你熟悉了大量的 twang 的身体感觉，你就不需要再展宽舌头了。熟练使用 Edge 的歌手有时会使用展宽舌头以外的方法调整模式。

### 通过声音找到 Edge Finding Edge through sound
**Edge 模式的声道非常窄小，因此音色非常亮**。会厌漏斗越挤，声音就越尖锐。声音必须有力、咆哮且尖锐。声音必须带有清晰的 "金属" 音。

你可以通过以下方式找到 Edge：

- 模仿婴儿的哭喊声。
- 模仿鸭子嘎嘎的叫声。
- 发出像女巫一样的声音。
- 像一个有邪恶计划的人那样说话。
- 模仿飞机俯冲的声音。
- 发出驾驶玩具车的声音。
- 模仿救护车警笛的声音。
- 像猫一样 “Meow”（但不包含 “OO” 的尾音），或说 “niet”。

感受舌头在口腔上部臼齿内侧前后移动的感觉。分别对每个添加 twang 的元音进行练习，直到声音变得尽可能尖锐刺耳。练习在每个元音上发出最响亮的声音。

留意 Edge 模式动态平衡的感觉（不应该感到不适或不适），不断练习，直到发出有力、尖锐、刺耳且清晰的 "金属" 音。对某些歌手来说，最好先习惯声音的听感，再关注动态平衡的身体感觉。熟练之后，Edge 的音色和动态平衡便手到擒来。音色的尖锐程度也能随心所欲。请记住，Edge 必须保持一定的尖锐听感。

Edge 没有统一的体感。因此你不能通过体感找到它。虽然嗓音模式无法通过体感找到，但可以通过听感找到。

如果模式很难把握，可以从一个有力、特别尖锐刺耳的声音开始摸索。熟悉了模式的听感之后，你就可以把音量调低，也可以把音色调整得不那么尖锐锋利。请注意，在模式中心区演唱通常会比在非中心区演唱消耗更少的支承力。

### 在 Edge 模式下，留意下颌和会厌漏斗的位置 Be careful about the position of the jaw and the epiglottic funnel in Edge
**与 Overdrive 模式一样，初学阶段要注意不要放松下颌**如果下颌是放松的，你可能会丢失添加 twang 的会厌漏斗的位置和清晰的 "金属" 音。这可能听起来像是破音，会伤嗓。请牢记，如果会厌漏斗挤压不够，嗓音就会脱离 Edge 模式，变为 Curbing 或 Neutral。完全掌握 Edge 后，你就可以随心所欲地调整下颌位置了。

练习 Edge 时如果感觉喉咙痛，说明添加 twang 的会厌漏斗的位置不够窄。**会厌漏斗不够窄可能因为喉位不够高**。在这种情况下，让会厌漏斗再收窄一些、舌头再展宽一些、喉位再抬高一些、微笑再夸张一些、达到相对响亮的音量，能有助于添加清晰的 "金属" 音、保护嗓音。
