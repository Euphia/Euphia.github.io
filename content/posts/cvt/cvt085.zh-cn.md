## Edge 模式的音色 Sound colours in Edge
想改变模式音色，就必须改变声道形状。我们可以从各个方向角度调整声道形状，所以改变音色的方法有无数种。 

> 请参阅 "音色" - page 186

Edge 的音色通常明亮、尖锐，但音色也可以向其他方向调整。用 Edge 塑造亮音色并不难，但如果想塑造暗音色，你就必须完全掌控三大总体原则。除此之外，你还必须对自己的声音了如指掌，以便在超出健康极限时有所察觉。牢记：“金属” 音越亮，就越能防止声音使用不当。只有在毫无问题地掌握 Edge 后，你才可以尝试让 Edge 的音色变暗。 

**只有在毫无问题地掌握 Edge 后，你才能尝试改变音色**——浅尝辄止即可。你可以通过改变发音位置和声道形状将音色变暗，但请记住，使音色变暗的过程中，可能会出现问题。因为音色越暗，丢失 “金属” 音的风险越大。请牢记保持住清晰的强 “金属” 音和大量的 twang、避免脱离 Edge 模式。 

### Edge 模式较亮的音色 Lighter sound colour in Edge
如果想让 Edge 音色更亮，你必须缩小声道的尺寸。可以选择以下一种或多种方法实现： 

- 挤压会厌漏斗添加大量的 twang
- **进一步抬高喉位**
- 放松软腭
- 打开口腔，像在微笑一样
- 进一步展宽舌头
- 进一步打开鼻腔通道

### Edge 模式的不那么亮的音色 Less light sound colour in Edge
如果你想在 Edge 模式下发出更柔和或更暗的音色，你可以稍微扩大声道的尺寸。可以选择以下一种或多种方法实现： 

- 挤压会厌漏斗添加少量的 twang。对此要非常谨慎。请记住，大量的 twang 是 Edge 模式的必要条件。
- 如果你很有经验，你可以尝试稍微压低喉位。再次提醒，注意不要丢失清晰的强 “金属” 音和大量的 twang。请记住：Edge 越亮，模式越安全。
- **如果你经验丰富，可以尝试稍微提软腭**。注意不要过度提软腭，以免丢失清晰的强 “金属” 音和大量的 twang，因为这样可能会造成疼痛和损伤。
- 放松嘴角、口型更大，但不要丢失 “咬住” 的动作。再次提醒，注意不要丢失清晰的强 “金属” 音和大量的 twang。
- 舌头下凹成直沟。这样发音类似歌剧唱法。再次提醒，注意不要丢失清晰的强 “金属” 音和大量的 twang。
- 关闭鼻腔通道。

### 案例故事 A case story
一位摇滚歌手在唱高音时遇到了问题。她上过很多歌唱课，但觉得自己没有进步，对练习感到厌倦。 

我让她像在舞台上那样唱歌，然后给我看她的练习内容。她练习时用的是 Neutral，但在舞台上唱歌时主要用 Edge。所以她的练习对提高歌唱没有任何效果，是完全合理的。想提高在 Edge 模式下的歌唱能力，就必须在 Edge 模式下练习。 

当我们练习 Edge 模式中心区时，我发现**她的会厌漏斗挤压不够，这就是她难以达到高音的原因**。重新练习之后，她掌握了 Edge 正确的发音方式，于是我们把这项技术运用到歌曲中。而接下来，我们不得不解决她的另一个问题：元音。我们练习调整元音发音，使其接近 "I" ("sit" [ɪ])、"EH" ("stay" [ɛ])、"A" ("and" [æ]) 和 "OE" ("herb" [ɜr])。掌握了 Edge 的正确发音位置、并学会在 Edge 模式下使用正确的元音之后，高音对她来说就不再是问题了。 

### 古典唱法里的 Edge 模式 Edge in classical singing
在古典乐中，在中等响亮至响亮（mf-ff）的乐段，Edge 常用来表现清晰的 “金属” 音（“金属” 音通常很难捕捉到，因为它被较暗的音色盖住了）。古典男歌手可以在所有音区使用 Edge 模式，Edge 在高音区听感清晰，比如男高音唱 C5。**古典女歌手在中低音区以中等响亮至响亮音量的演唱时，大多采用 Edge 模式**。 

技术上很难在 Edge 模式下使用古典唱法所需的暗音色。你只有在习惯了古典唱法、完全掌握了 Edge，并了解正确使用声音的三大总体原则后，才能尝试这种唱法。除此之外，你还必须对自己的声音了如指掌，以便在超出健康极限时有所察觉。 

从 Edge 模式的中心区开始练习 。熟悉有力、明亮、清晰的 "金属" 音。现在，请谨慎地尝试提软腭，放松嘴角、打开口腔、下凹舌头成直沟，关闭鼻腔通道——保证所有这些动作都不会影响清晰的强 “金属” 音和大量的 twang。在你舒适的音高下唱单音，随着音高升高，保持这种音色。 

熟悉这种感觉后，尝试一下 - 仍然只唱单音 - 看看你能在不明亮清晰的 “金属” 音情况下将喉位压低多少。声道越大，音色就越暗、越古典。 

古典男歌手，在需要非常响亮和有穿透力的声音时（例如卢西亚诺·帕瓦罗蒂和普拉西多·多明戈），会在 A4-Bb4 左右及以上使用 Edge 模式。 

### 案例故事 A case story
一家大型歌剧公司的首席男高音遇到了严重的问题，因为他的声从高音 C 就开始破音。他的高音 C 一直不太稳定，他不知道自己能否保持高音 C，也不知道声音是否会破音。但现在，破音变得更频繁了。他非常绝望，因为当晚他就要唱歌了，而他却越练越糟。 

**事实证明，他和许多歌剧演员一样，被教导要将喉位尽量放低**。他越这样，高音就越受影响。先是随着音越唱越高，练习将喉位逐渐抬高。他的声音变得更稳定，即使在音量很小的情况下，也能将几乎所有元音发准。为了在高音上获得更有力的音量，我们向 Edge 添加了大量的 twang，直到他掌握了这种强 “金属” 音。 

过了一段时间，在只使用元音 "I" ("sit" [ɪ])、"EH" ("stay" [ɛ])、"A" ("and" [æ]) 和 "OE" ("herb" [ɜr]) 的前提下，他能在 Edge 模式中心区用高音区唱出所有音高了。他的高音不再颤抖、甚至可以发出非常响亮的音量。接下来，我们尝试通过谨慎地使音色变暗、稍微压低喉位、抬软腭和关闭鼻腔通道，使 Edge 听起来更古典。 

我们还尝试将音色调暗到他的声音开始颤抖的程度。这样做是为了让他意识到，在喉位压低到一定程度之前，他就会遇到麻烦，并且知道在表演时如果发生这种情况该怎么办。每当高音快要失控时，他都会回到 Edge 模式中心区来稳定乐句。当他完全掌握后，保持高音不再困难——他可以发出比以前更响亮的声音，并且知道如何避免声音破音。他毫无问题地完成了当晚的演出。
