## Edge 模式的元音 Vowels in Edge
### 使用精确的主元音 Use precise main vowels
确保正确的元音发音非常重要，因为这样技术才能行之有效。不同的语言和方言会让你不自觉地使用其他元音，而不是对的元音。因此，我建议你一开始就仔细研究 CVT 声音库中的声音示例, 通过听辨和模仿学习每种情况下元音的细微差别，以便识别和复现。

某些元音在一些语言中并不存在，CVT Sound Library 中的某些元音与你的语言或方言中的元音发音并不完全相同，因为 CVT Sound Library 中的元音是以英语为基础、为所有语言制作的。有疑问时，请参考 CVT Sound Library 和本概述，并在开始练习前充分了解需要发出的元音。

> Edge 模式下的元音 “OE”（如在 “herb” 中）


在 Edge 模式下，你只能使用加入 twang 的元音 “I”（如在 “sit” 中）、“EH”（如在 “stay” 中）、“A”（如在 “and” 中）和 “OE”（如在 “herb” 中）。注意，在 Edge 模式下，所有元音都必须带有清晰的 “金属” 音，以避免转换模式。许多元音的发音非常接近，但重要的是，你必须能够准确地区分各种元音，并且能够准确地识别出在特定模式下所需的元音。

乍看之下，似乎所有元音都可以在低音区用 Edge 模式演唱，因为这里的嗓音模式彼此相似。但是，如果想保持在 Edge 模式下，你必须将元音改为有清晰金属音的 “I”、“EH”、“A” 和 “OE” 。

因此，“EE” 被改为 “I”。例如，将 'Hey Baby' 更改为 'H-EH, b-EH-b-I'。



> "Hey Baby" 在 Edge 模式下改变元音


“AH” 改为 “A”，“OO”、“O” 和 “OH” 改为 “OE”。例如，将 "I love you" 改为 "A-i l-OE-ve y-OE"。



> “I love you” 在 Edge 模式下改变元音


“AH” 常常要改为 “A”。例如，将 "love my father" 改为 "l-A-ve mA-i f-A-ther"。

在 Edge 模式下演唱元音 "I"（如在 "sit "中）和 "EH"（如在 "stay "中）时，你需要相当准确地辨别元音细微差别，这样技术才能以正确的方式发挥作用。

元音'A'（如在'and'中）和'OE'（如在'herb'中）有更多的可能性，而且变化很大。这意味着你可以使用更广泛的元音的微妙变化，并且该技术仍然奏效。

元音 'A'（如在 'and '中）可以是丹麦语的 'A'（如在 'abe '中）、英语的 'hat' 或法语的 'A'（如在 'plage' 中）。



> 元音 A


此外，元音 'OE'（如在 'herb' 中）可以从德语 'Ö'（如在 'öhr' 中）变化到英语 'OE'（如在 'herb' 中），变化很大。



> 元音 OE





为了保持大量的 twang 和清晰的 “金属” 音，可以在 Edge 模式下将舌根保持在较高位置。舌头两侧紧贴上颚，舌尖向下。用这个舌头位置，你就能发出加入 twang 的元音。在 Edge 模式下，你只能使用 “I”、“EH”、“A” 和 “OE”，因为这些元音有助于保持大量的 twang 和清晰的 “金属” 音。




元音“EE”（如在“see”中）也可以在 Edge 模式下使用，但由于它往往会诱使你转换到 Neutral 模式，从而失去 “金属” 音，因此出于教学目的，它不作为 “Edge 元音” 包含在内。我们选用元音 “I”，因为用“ 金属” 音塑造元音 “I” 更容易。



> Edge 模式下的元音 “EE”


唱 ‘I’ 加入清晰的 “金属” 音，感受舌根的位置。在 Edge 模式下，在所有元音上保持这个位置。

在 Edge 模式下，元音 “I” 可能很难唱出来，因为声音可能会变成 Curbing。为了避免 “I” 发出 “Curbing” 模式克制的 “金属” 音，要使用亮音色、更快了，使用清晰的 “金属” 音。

在 Edge 模式下，所有 “A” 元音的发音都如平舌音 “A” (如在 “and” 中)。这意味着 “AH” (如在 “far” 中) 的发音应如 “A” (如在 “and” 中)。

请注意，在 Curbing 模式下，Edge 的 A 音不要发成 “UH”。通过将元音指向更明亮、更“快乐”的 “A”（如在“and”中），可以避免 “Curbing” 模式中克制的 “金属” 音，同时保持清晰的 “金属” 音。

后元音如 “OO” (如在 “you” 中)、“O” (如在 “woman” 中) 和 “OH” (如在 “so” 中) 在 Edge 模式下无法发音，因为它们会降低舌位和喉位，并常常影响加入大量的 twang。因此，你必须将这些元音改为 “OE”（如在 “herb” 中）。将 “OO” 改为 “OOE”，将 “O” 改为 “OE”，将 “OH” 改为 “OEH”，所有这些发音都有清晰的 “金属” 音特点。可能需要一段时间才能习惯新的元音，所以请分开练习，直到完全掌握。




如果发元音时遇到问题，首先用你容易发出的 Edge 元音代替它，例如 “I” (如在 “sit” 中)。一旦你能控制好简单的元音，在学习困难的元音时，舌根就保持在这个精确的位置。请注意不要改变清晰的 “金属” 音。

练习了 Edge 模式下的元音后，你还需要练习 Edge 模式下的辅音。在 Edge 模式下找到舌头的位置，然后唱元音 “I”。发出大量的 twang，留意舌头的位置较高，舌头两侧与上臼齿接触。保持这个舌头位置，保持嘴巴相对张开，并尝试仅通过移动舌尖来在 “L” 和 “N” 之间转换。用这种方法练习所有辅音，同时保持舌头的位置不变。

每个歌手将元音改为 “I”、“EH”、“A” 和 “OE” 的程度各不相同。相比经验不足的歌手，更有经验的歌手能够更好地探索 Edge 元音和其他元音之间的边界，同时又不失清晰的 “金属” 音。

首先，可以尝试将清晰的 “金属” 音发得夸张一些，以便在 Edge 模式下找到最舒服的发音。找到 Edge 并能够用健康的方式唱出 Edge 中的所有元音后，你可以练习减少元音中的 twang，并减少 “I”、“EH”、“A” 和 “OE” 的清晰度，同时保持清晰的 “金属” 音。

### 通过想象和身体感觉学习 Edge Achieving Edge through images and sensations
特别注意：这些想象和身体感觉仅作为辅助参考。如果你没有秒懂这些参考，就忘掉它。不要将它们与实际发生的事情混淆！

- 用拇指和食指在嘴边围成一个圈，在圈内嘟起嘴，就像你想叫某人一样。说出“OE”（如“herb”中的发音），感受舌尖两侧如何接触上颚的臼齿，以及舌尖前端如何形成一个小的碗状。在所有元音上，舌头都保持这个位置。



- 在练习所有元音时，无论声音是高音区还是低音区，都要保持口腔和舌根完全相同的位置，直到Edge 元音完美为止。
- 每个元音在高音区和低音区都要相同。
- 当你发出辅音时，感受嘴唇往往向前移动，舌头向后移动，以保持 Edge。
- 使用 Edge 时，在吸气时保持舌头在 Edge 位置可能会有帮助。
