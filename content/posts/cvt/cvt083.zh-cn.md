## Edge 模式的元音 Vowels in Edge
### 使用精确的主元音 Use precise main vowels
确保正确的元音发音非常重要，因为这样技术才能行之有效。不同的语言和方言会让你不自觉地使用其他元音，而不是对的元音。因此，我建议初学者仔细研究 CVT 声音库中的声音示例， 通过听辨和模仿学习每种情况下元音的细微差别，以便识别和复现。

某些元音在一些语言中并不存在，CVT Sound Library 中的某些元音与你的语言或方言中的元音发音并不完全相同，因为 CVT Sound Library 中的元音是以英语为基础、为所有语言制作的。有疑问时，请参考 CVT Sound Library 和本概述，并**在开始练习前花时间想清楚你需要哪个元音**。

> 音频示例 - Edge 元音 "EH" ("stay" [ɛ])

> 音频示例 - Edge 元音 "A" ("and" [æ])

> 音频示例 - Edge 元音 "OE" ("herb" [ɜr])

在 Edge 模式下，你只能使用添加 twang 的元音 “I” (“sit” [ɪ])、“EH” (“stay” [ɛ])、“A” (“and” [æ]) 和 “OE” (“herb” [əu])。注意，在 Edge 模式下，为避免改变模式，所有元音都必须带有清晰的 “金属” 音。许多元音的发音非常接近，你必须能够准确地区分各种元音，并且能够准确地识别出保持在特定模式下所需的元音。

乍看之下，似乎所有元音都可以在低音区用 Edge 模式演唱，因为这里的嗓音模式彼此相似。但是，如果想保持在 Edge 模式下，你必须将元音调整为带有清晰 "金属" 音的 “I”、“EH”、“A” 和 “OE” 。

因此，“EE” 的发音要调整得接近 “I” 的发音。例如，将 'Hey Baby' 的发音调整得接近 'H-EH, b-EH-b-I'。

> 音频示例 - "Hey Baby" 在 Edge 模式下调整元音

“AH” 的发音要调整得接近 “A” 或 “OO” 的发音， “O” 和 “OH” 的发音要调整得接近 “OE” 的发音。例如，将 "I love you" 的发音调整得接近 "A-i l-OE-ve y-OE"。

> 音频示例 - “I love you” 在 Edge 模式下调整发音

“AH” 的发音往往会调整得接近 “A” 的发音。例如，将 "love my father" 的发音调整得接近 "l-A-ve mA-i f-A-ther"。

用 Edge 模式演唱，无论是 “I”(“sit”[ɪ]) 还是 “EH”（“stay”[ɛ]），你都需要精确地分辨元音细微听感，使技术行之有效。

元音 "A" ("and" [æ]) 和 "OE" ("herb" [ɜr]) 的发音有更多的可能性、并且变化很大。这意味着你可以使用更多的可能的发音，同时技术仍然奏效。

元音 "A" ("and" [æ]) 可以是丹麦语的 'A'（ 'abe' [aːbə]）、英语的 'hat' [hæt]） 或法语的 'A'（ 'plage' [plaʒ]）。

> 音频示例 - "A" 系列元音

此外，元音 "OE" ("herb" [ɜr]) 可以是德语的 'Ö'（如在 'öhr' [øːr]），也可以是英语 的"OE" ("herb" [ɜr])，变化很大。

> 音频示例 - "OE" 系列元音

为了保持大量的 twang 和清晰的 “金属” 音，你可以在 Edge 模式下将舌根保持在较高位置。舌头两侧紧贴上颚，舌尖向下。你可以在这个舌位下发出添加 twang 的元音。在 Edge 模式下演唱，你只能使用元音 “I”、“EH”、“A” 和 “OE”，因为这些元音有助于保持大量的 twang 和清晰的 “金属” 音。

元音 "EE" ("see" [i]) 也可以在 Edge 模式下使用，但由于它往往会诱使你改变模式为 Neutral、丢失 “金属” 音，因此出于教学目的，它没有被列为 Edge 元音。因此我不用元音 "EE" ，而是用在 "金属" 模式下相对更容易唱准的 “I” 作为 Edge 元音。

> 音频示例 - 元音 "EE" ("see" [i])

**向 “I” 添加清晰的 “金属” 音，感受舌根的位置**。用 Edge 演唱时，所有元音保持这个位置。

用 Edge 发元音 “I” 可能也有些难度，因为模式有可能倾向 Curbing。你要使用清晰的 “金属” 音、发出更明亮、“欢快” 的音色，以避免元音 ’I“ 带有 “Curbing” 模式克制的 “金属” 音。

在 Edge 模式下，所有 “A” 系列元音的发音都要像 "A" ("and" [æ]) 扁平版这意味着 "AH" ("far" [ɑː]) 应该向 "A" ("and" [æ]) 那样发音。

**请注意不要将 Edge 的元音 “A” 发成 Curbing 元音 “UH”**。将元音发成更明亮、 “快乐”的 "A" ("and" [æ])，可以避免 “Curbing” 模式中克制的 “金属” 音，同时保持清晰的 “金属” 音。

在 Edge 模式下无法使用后元音如"OO" ("you" [u])、“O”("woman" [o])和 “OH” ("so" [oʊ] 的开头) ，因为它们会降低舌位和喉位、因此常常阻碍添加大量的 twang。因此，你必须将这些元音发音调整得更接近 “OE” ("herb" [ɜr])。“OO” 就变成了 “OOE”，“O” 就变成了 “OE”，“OH” 就变成了 “OEH”，所有这些发音都有清晰的 “金属” 音。可能需要一段时间才能习惯新的元音，所以请分别练习每个元音，直到完全掌握。

**如果发元音时遇到问题，首先用你容易发出的 Edge 元音代替它**，例如 "I" ("sit" [ɪ])。完全掌握简单的元音发音之后，学习困难的元音时，记得把舌根保持在这个精确的位置。请注意不要改变清晰的 “金属” 音。

练习了 Edge 模式下的元音后，你还需要练习 Edge 模式下的辅音。在 Edge 模式下找到舌头的位置，然后唱元音 “I”。添加大量的 twang，注意舌位要搞、舌两侧要碰到上颚。保持这个舌位、保持相对大的口型，并尝试仅通过移动舌尖来在 “L” 和 “N” 之间转换。用这种方法练习所有辅音，同时保持舌头的位置不变。

每个歌手将元音调整为 “I”、“EH”、“A” 和 “OE” 的程度各不相同。相比经验不足的歌手，技术成熟的歌手有能力更好地探索 Edge 元音和其他元音之间的边界，同时又不失清晰的 “金属” 音。

在初学阶段，你可以尝试将清晰的 “金属” 音发得夸张一些，以便在 Edge 模式下找到最舒服的发音。找到 Edge 并能够用健康的方式唱出 Edge 中的所有元音后，你可以练习减少元音中的 twang，并降低 “I”、“EH”、“A” 和 “OE” 的清晰度，同时保持清晰的 “金属” 音。

### 通过想象和身体感觉学习 Edge Achieving Edge through images and sensations
特别注意：这些想象和身体感觉仅作为辅助参考。如果你没有秒懂这些参考，就忘掉它。不要将它们与实际发生的事情混淆！

- 用拇指和食指在嘴边围成一个圈，在圈内嘟起嘴，就像你想叫某人一样。发元音 "OE" ("herb" [ɜr])，感受舌尖两侧如何接触上颚的臼齿，以及舌尖前端如何形成一个小的碗状。发所有元音时，舌头都保持在这个位置。

- 在练习所有元音时，无论声音是高音区还是低音区，都要保持口型和舌位完全相同，直到Edge 元音完美为止。
- **每个元音在高音区和低音区都要有相同的听感**。
- 发辅音时，感受嘴唇向前移动、舌头向后移动，以保持 Edge。
- 使用 Edge 时，吸气的同时保持舌头在 Edge 位置可能会有帮助。
