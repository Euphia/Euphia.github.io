## Edge 模式的元音 Vowels in Edge
### 使用精确的主元音 Use precise main vowels
确保正确的元音发音非常重要，因为这样技术才能行之有效。不同的语言和方言会让你不自觉地使用其他元音，而不是对的元音。因此，我建议初学者先仔细研究 CVT 声音库中的声音示例， 通过听辨和模仿学习每种情况下元音的细微差别，以便识别和复现。

某些元音在一些语言中并不存在，CVT Sound Library 中的某些元音与你的语言或方言中的元音发音并不完全相同，因为 CVT Sound Library 中的元音是以英语为基础、为所有语言制作的。有疑问时，请参考 CVT Sound Library 和本概述，并在开始练习前充分了解需要使用的元音。

> 请参阅 "音量和嗓音模式"

> 音频示例 - Edge 元音 “I” (“sit” [ɪ])

> 音频示例 - Edge 元音 "EH" ("stay" [ɛ])

> 音频示例 - Edge 元音 "A" ("and" [æ])

> 音频示例 - Edge 元音 "OE" ("herb" [ɜr])

在 Edge 模式下，你只能使用添加 twang 的元音 “I” (“sit” [ɪ])、“EH” (“stay” [ɛ])、“A” (“and” [æ]) 和 “OE” (“herb” [əu])。注意，在 Edge 模式下，所有元音都必须带有清晰的 "金属" 音，以避免改变模式。许多元音的发音非常接近，你必须能够准确地区分各种元音，并且能够准确地识别出在特定模式下所需的元音。

乍看之下，似乎所有元音都可以在低音区用 Edge 模式演唱，因为这里的嗓音模式彼此相似。但是，如果想保持在 Edge 模式下，你必须将元音调整为有清晰 "金属" 音的 “I”、“EH”、“A” 和 “OE” 。

因此，调整 “EE” 的发音，使其接近 “I”。例如，将 'Hey Baby' 调整为 'H-EH, b-EH-b-I'。

> 音频示例 - "Hey Baby" 在 Edge 模式下调整元音

调整 “AH” 的发音，使其接近 “A”，“OO”、调整 “O” 和 “OH” 的发音使其接近 “OE”。例如，将 "I love you" 调整为 "A-i l-OE-ve y-OE"。

> 音频示例 - “I love you” 在 Edge 模式下调整发音

常常要调整 “AH” 的发音，使其接近 “A”。例如，将 "love my father" 调整为 "l-A-ve mA-i f-A-ther"。

用 Edge 演唱 “I”（“sit”[ɪ]) 或 “EH”（“stay”[ɛ]），你都需要精确地分辨元音细微听感，技术才能行之有效。

元音 "A" ("and" [æ]) 和 "OE" ("herb" [ɜr]) 有更多的可能性，而且变化很大。这意味着你可以使用更广泛的元音的微妙变化，并且该技术仍然奏效。

元音 "A" ("and" [æ]) 可以是丹麦语的 'A'（如在 'abe '中）、英语的 'hat' 或法语的 'A'（如在 'plage' 中）。

> 音频示例 - 元音 A

此外，元音 "OE" ("herb" [ɜr]) 可以从德语 'Ö'（如在 'öhr' 中）变化到英语 "OE" ("herb" [ɜr])，变化很大。

> 音频示例 - 元音 OE

为了保持大量的 twang 和清晰的 "金属" 音，可以在 Edge 模式下将舌根保持在较高位置。舌头两侧紧贴上颚，舌尖向下。用这个舌头位置，你就能发出添加 twang 的元音。在 Edge 模式下，你只能使用 “I”、“EH”、“A” 和 “OE”，因为这些元音有助于保持大量的 twang 和清晰的 "金属" 音。

元音 "EE" ("see" [i]) 也可以在 Edge 模式下使用，但由于它往往诱使你改变模式变成 Neutral，从而丢失 "金属" 音，因此出于教学目的，它没有被列为 Edge 元音。我们选用元音 “I”，因为用 "金属" 音塑造元音 “I” 更容易。

> 音频示例 - 元音 "EE" ("see" [i])

唱 ‘I’ 并添加清晰的 "金属" 音，感受舌根的位置。用 Edge 演唱时，所有元音保持这个位置。

用 Edge 发元音 “I” 可能很难，因为声音可能会变成 Curbing。为了避免 “I” 发出 “Curbing” 模式克制的 "金属" 音，要使用亮音色、更 “欢快”，就要使用清晰的 "金属" 音。

在 Edge 模式下，所有 “A” 元音的发音都如扁扁的 "A" ("and" [æ])。这意味着 "AH" ("far" [ɑː])的发音应如 "A" ("and" [æ])。

请注意，在 Curbing 模式下，Edge 的 “A” 音不要发成 “UH”。通过将元音指向更明亮、更“快乐”的 "A" ("and" [æ])，可以避免 “Curbing” 模式中克制的 "金属" 音，同时保持清晰的 "金属" 音。

后元音如 "OO" ("you" [u])、“O”("woman" [o])和 “OH” ("so" [oʊ] 的开头) 在 Edge 模式下无法发音，因为它们会降低舌位和喉位，并常常影响添加大量的 twang。因此，你必须将这些元音调整为 “OE” ("herb" [ɜr])。将 “OO” 调整为 “OOE”，将 “O” 调整为 “OE”，将 “OH” 调整为 “OEH”，所有这些发音都有清晰的 "金属" 音特点。可能需要一段时间才能习惯新的元音，所以请分开练习，直到完全掌握。

如果发元音时遇到问题，首先用你容易发出的 Edge 元音代替它，例如 "I" ("sit" [ɪ])。一旦你能控制好简单的元音，在学习困难的元音时，舌根就保持在这个精确的位置。请注意不要改变清晰的 "金属" 音。

练习了 Edge 模式下的元音后，你还需要练习 Edge 模式下的辅音。在 Edge 模式下找到舌头的位置，然后唱元音 “I”。添加大量的 twang，留意舌头的位置较高，舌头两侧与上臼齿接触。保持这个舌头位置，保持嘴巴相对张开，并试着仅通过移动舌尖来在 “L” 和 “N” 之间转换。用这种方法练习所有辅音，同时保持舌头的位置不变。

每个歌手将元音调整为 “I”、“EH”、“A” 和 “OE” 的程度各不相同。相比经验不足的歌手，更有经验的歌手能够更好地探索 Edge 元音和其他元音之间的边界，同时又不失清晰的 "金属" 音。

首先，可以试着将清晰的 "金属" 音发得夸张一些，以便在 Edge 模式下找到最舒服的发音。找到 Edge 并能够用健康的方式唱出 Edge 中的所有元音后，你可以练习减少元音中的 twang，并减少 “I”、“EH”、“A” 和 “OE” 的清晰度，同时保持清晰的 "金属" 音。

### 通过想象和身体感觉学习 Edge Achieving Edge through images and sensations
特别注意：这些想象和身体感觉仅作为辅助参考。如果你没有秒懂这些参考，就忘掉它。不要将它们与实际发生的事情混淆！

- 用拇指和食指在嘴边围成一个圈，在圈内嘟起嘴，就像你想叫某人一样。发元音 "OE" ("herb" [ɜr])，感受舌尖两侧如何接触上颚的臼齿，以及舌尖前端如何形成一个小的碗状。在所有元音上，舌头都保持这个位置。

- 在练习所有元音时，无论声音是高音区还是低音区，都要保持口腔和舌根完全相同的位置，直到Edge 元音完美为止。
- 每个元音在高音区和低音区都要相同。
- 当你发出辅音时，感受嘴唇往往向前移动，舌头向后移动，以保持 Edge。
- 使用 Edge 时，在吸气时保持舌头在 Edge 位置可能会有帮助。
